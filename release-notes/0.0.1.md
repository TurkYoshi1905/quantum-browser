# QuantumBrowser v0.0.1 — "İlk Işık"

**Yayın tarihi:** Kasım 2026
**Platform:** Windows 10/11 (x64)
**Lisans:** GNU AGPL-3.0
**Derleme:** Tauri v2 · Rust · React

QuantumBrowser'ın ilk genel derlemesi. Gizlilik öncelikli, reklam engellemeli,
Arc tarzı ferah arayüze sahip açık kaynak masaüstü tarayıcısı — sıfır telemetri
ile, davranışlarınız bu cihazdan çıkmaz.

## Öne çıkanlar

### Quantum Şifre Kasası (yeni)
- Ana parola ile kilitlenen, cihazınızda yerel şifreli kasanız.
- Argon2id ile anahtar türetme, AES-256-GCM ile uçtan uca şifreleme.
- Düz metin şifre hiçbir zaman diske yazılmaz; kasap kilitliyken yalnızca
  şifreli bloblar görünür.
- Web sitesinde kayıtlı girişinizi arama, güçlü parola üretecisi (18 karakter),
  tek tıkla panoya kopyalama (silme 30 saniye sonra), şifreli dışa/içe aktarım.
- `quantum://vault` adresinde veya Ayarlar → Quantum Şifre Kasası üzerinden açılır.

### HTTPS Zorunluluğu (yeni)
- HTTP (şifresiz) adresler otomatik olarak engellenir; "Bu site güvenli değil"
  uyarı sayfasıyla karşılaşırsınız.
- **Yine de devam et** seçeneği — tavsiye edilmez, tek seferliktir.
- Ayarlar → Gizlilik & Engelleme → "HTTP siteleri engelle" ile açık/kapalı yapılabilir.

### Tarayıcı çekirdeği
- **Reklam ve izleyici engelleyici** — yerleşik, ~110 bilinen alan adı Chromium
  seviyesinde kesilir; engel sayısı sekme şeridindeki kalkan rozetinde görünür.
- **Dikey sekme çubuğu + sekme grupları** — sürükleyip gruplama, sabitleme,
  çoğaltma, `Ctrl+Shift+T` ile kapattıklarını geri açma.
- **Oturum geri yükleme** — kapattığınızda açık sekmeler geri gelir (Ctrl+Shift+T).
- **Çoklu profil + gizli mod** — profiller ayrı WebView2 veri dizinleriyle izole;
  gizli sekmeler diske hiçbir şey yazmaz.
- **Yer imleri ve geçmiş** — FTS5 ile tam metin arama; toplu seçim ve silme.
- **Yerel indirme yöneticisi** — `Downloads/QuantumBrowser` klasörüne; indirilen,
  tamamlanan, yarıda kalanlar Ayarlar → İndirmeler'de.
- **quantum:// iç sayfalar** — Ayarlar, Geçmiş, Yer İmleri, İndirmeler, Profiller,
  Yeni Sekme, Şifre Kasası; hepsi Chrome'un iç sayfaları gibi sekmede açılır.

### Tasarım
- Açık / koyu / sistem teması — tüm iç sayfalarda **anlık** senkron.
- Vurgu rengi (accent) seçici — mor, mavi, ferah teal, amber, yeşil, kırmızı;
  seçim tüm ekranlara ve kalıcı olarak kaydedilir.
- Premium Yeni Sekme — saat, tarih, selamlaşma, hızlı erişim ızgarası.
- Lucide ikon seti, sıfır emoji, tutarlı 4px ızgara.

## Bilinen sınırlar
- Chrome uzantıları desteklenmez (WebView2/Edge eklenti modeli yoktur).
- Bazı siteler Google kimliğiyle 403 dönebilir (WebView2 bilinen davranışı).
- DRM korumalı içerikte (ör. Netflix) oynatma farklılık gösterebilir.
- Derleme imzasızdır; SmartScreen uyarısı için **More info → Run anyway**.

## Kurulum
1. `QuantumBrowser_0.0.1_x64-setup.exe` dosyasını indirin.
2. Çalıştırın; Windows uyarısı görürseniz **More info → Run anyway** seçin.
3. WebView2 Runtime gerekir (Windows 11'de yerleşik; yoksa kurulumcu indirir).
4. Kurulum "Kullanıcı" kapsamındadır; yönetici hakkı gerekmez.

## Doğrulama (SHA256)
İndirdiğiniz dosyanın bütünlüğünü doğrulayın:

```powershell
Get-FileHash .\QuantumBrowser_0.0.1_x64-setup.exe -Algorithm SHA256
```
```cmd
certutil -hashfile QuantumBrowser_0.0.1_x64-setup.exe SHA256
```
Hash, bu sürüm notunun altında ve release sayfasındaki `SHA256SUMS.txt` dosyasında yazar.

## Gizlilik sözü
QuantumBrowser telemetri toplamaz, reklam ağına göndermez, profilinizi senkron
etmez. Verileriniz yalnızca cihazınızdaki `%LOCALAPPDATA%\com.quantum.browser`
klasöründe SQLite veritabanlarındadır. Şifre kasanıza yalnızca siz
(ana parolanızla) erişebilirsiniz; geliştirici dahil kimse göremez.
