# QuantumBrowser v0.0.3 — "Kendini Güncelleyen"

**Yayın tarihi:** Kasım 2026
**Platform:** Windows 10/11 (x64)
**Lisans:** GNU AGPL-3.0
**Derleme:** Tauri v2 · Rust · React

Bu sürüm, QuantumBrowser'ın en önemli yaşam kalitesi özelliğini getirir:
utonomous güncelleme. Ayrıca popup sorunu bu döngüde kalıcı olarak
çocuk-webview mimarisine bağlandı (v0.0.2).

## Öne çıkanlar

### Uygulama içi güncelleme (yeni — A+C)
- **Açılışta sessiz kontrol** — açılır açılmaz GitHub release'lerine bakar;
  yeni sürüm varsa Ayarlar dişlisinde mor rozet gösterir (varsayılan açık,
  Ayarlar'dan kapatılabilir).
- **Ayarlar → Güncelleme** — mevcut sürümü, son kontrolü ve (varsa) yeni
  sürümün notlarını görür; **"Şimdi Güncelle"** düğmesi tek dokunuşla
  imzalı installer'ı indirir ve üzerine kurar — eski sürüm silinmez,
  ayarlarınız ve şifre kasanız korunur.
- **İmzalı güncellemeler** — her release CI'da minisign ile imzalanır;
  uygulama `tauri-plugin-updater` ile imzayı doğrulamadan hiçbir şey
  kurmaz. İmzasız/bozuk paket asla kurulmaz.
- Güncellemeler GitHub Releases'tan iner — harici sunucu gerekmez.

### İndirme baloncuğu (düzeltme)
Kabuğun tamamını kapatan "overlay" kalıbı kaldırıldı; indirme tamamlandı
baloncuğu artık sayfalarla aynı çocuk-webview motorunda çizilir.
Sayfa yok edilmez, kabuk donmaz, tıklamalar normal çalışır.
(v0.1'den beri süregelen "indirme bildiriminde boş ekran" sınıfı sorun
kesilmiştir.)

## Nasıl güncelleyeceğim?

1. Ayarlar → Güncelleme kartında **"Güncellemeleri Denetle"** düğmesine basın.
2. Yeni sürüm görürseniz **"Şimdi Güncelle"**'ye basın — yaklaşık 5 saniye
   sürer, uygulama kapanır, kurulur, yeniden açılır.
3. İlk kez (v0.0.2 veya eski sürümü imzasız updater'sız kurmuşsanız) bir
   defa elle v0.0.3 kurun; bundan sonra güncellemeler tek dokunuşla gelir.

## Teknik notlar
- `tauri-plugin-updater` (resmi plugin) + GitHub Releases endpoint
  (`releases/latest/download/latest.json`).
- `minisign` imzası — public key `tauri.conf.json` içine gömülü;
  private key yalnızca CI secret'ında yaşar.
- NSIS kurulumcu `installMode: currentUser` — yönetici hakkı gerekmez.
- Sürüm kaynağı tek nokta: `tauri.conf.json` / `Cargo.toml` / `package.json` → 0.0.3.

## Bilinen sınırlar
- Chrome uzantıları desteklenmez (WebView2 sınırı).
- Bazı siteler Google kimliğiyle 403 dönebilir; DRM'li içerikte oynatma farklılaşabilir.
- Derleme kod imzasız — SmartScreen uyarısı normaldir (More info → Run anyway).
